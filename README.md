# Delta Dice

A d4 dice game in a triangle-shaped desktop window.

Download **DeltaDice-windows.zip** from the [latest release](../../releases/latest), unzip it, and run `DeltaDice.exe` (Windows 10/11, 64-bit).

Windows SmartScreen may warn that the app is unrecognized because it is not code-signed. Click **More info**, then **Run anyway**.
